# ResourceV2

A curated digital library of UI/UX, design, and web development resources, built to make discovering useful tools and inspiration easier.

## Overview

ResourceV2 brings useful digital resources together in one organized platform, making it easier to explore, search, and save helpful tools for creative and development workflows.

## Features
- Resource search
- Category filtering
- Favorites system
- Responsive design
- Organized resource collection

## Built With
- PHP
- HTML5
- CSS3
- JavaScript
